Mörkkis project was our first big project during the first year of studies. I was a developer in this project with 4 other students.
Mörkkis was made for a software production course where the main focus was to build an application using waterfall model.
Our project was graded 5/5.

I was in charge of creating invoice window. It collects all the invoices made and it has the ability to filter invoices by a certain time frame.
I was also partially in charge of front end, especially menu items and window borders. Pictures and logos were made by another student.

This project was my first step to building an application with an actual purpose. Mörkkis is an application for booking cabins, storing client information and invoices. This project taught me how to develop software as part of a team and how to use Git and Azure DevOps.
I also learned and understood a lot about XAML, C# and SQL.

The project and all of its features have been tested on a local SQL database and at this stage it is not safe for public deployment.

After compiling the project once, the 'morkkis.sql' file must be relocated to:
HousingApp\bin\Debug\net8.0-windows\…
After this everything should work as intended.
